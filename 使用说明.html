巫妖的远程魔导控制系统

简称“巫妖远控” · Windows 10 / 11 x64 · v0.2.2 家庭试用版

第一次使用，只做这几步

  1. 每台电脑双击“巫妖远控-安装版-0.2.2.exe”，点安装。
    安装器准备程序、远控组件、专网组件和快捷方式。安装包已包含官方组件，安装时允许 Windows 管理员许可；首次专网登录仍需联网。默认允许本机在配对后被控制；只想控制其他电脑时可取消该选项。
  2. 首次按提示登录个人专网。
    在“本机接入”点“登录个人专网”。两端需加入同一个专网，初次可使用同一家庭账号。账号属于你们，软件不代填账号密码。
  3. 配对一次。
    被控电脑首页点“复制连接码”，控制电脑点“配对电脑”粘贴。连接码具有控制权限，只在自己的设备使用。已有 RustDesk 的电脑保留原密码，首次连接可能需要原密码或远端确认。
  4. 以后点电脑，再点“连接桌面”。
    你和老婆可各自控制不同电脑。电脑需要开机并联网；睡眠、重启和登录前的接入仍需两端实测。

日常使用不需要配置 GitHub、IP 地址、端口或服务器。GitHub 仅用于发布和下载软件版本。

给电脑起名

首页点“给本机起名”，输入“老婆笔记本”“家里台式机”等名称。名称会保存，新复制的连接码会带上这个名字。已配对的电脑在设备卡片点“改名”，修改这份列表中的名称；重新配对会保留已有备注。

免费与高清

本程序免费使用，没有高清付费开关。默认请求原始画面、画质值 90、目标 30 fps；“画质与帮助”可以切换流畅或低带宽预设。实际清晰度、帧率和延迟取决于两端电脑、上传带宽和连接路径。

跨网络使用 Tailscale，其 Personal 方案目前适用于个人非商业用途，具体规则以服务方当前说明为准。本程序不限制你们各自连接不同电脑；双人异地并行连接尚待实测。

自动更新

管理器运行时，启动后及每 6 小时检查新版本，验证发布者签名、更新包及每个文件的哈希。下载后在空闲时更新并重新打开。管理器更新不替换正在运行的远控引擎，设备列表、配对信息和远控配置保存在独立位置。失败时尝试恢复旧文件。

“软件更新”中可关闭自动检查或自动安装，也可立即检查。安装版可随 Windows 登录在托盘运行；关闭窗口会收起到托盘，托盘菜单可完全退出。完全退出期间不会检查更新。

更新来源：使用本项目的 GitHub 公开发布页。各台电脑联网时检查同一更新源，只有出现更高版本才会升级；公开地址的下载与签名校验记录随发布提供。远控引擎由 RustDesk 自身官方更新机制维护。

安全、两个人使用与 VPN

默认接入限制在个人专网地址。每台新装的被控电脑使用独立随机口令，保存的配对信息由 Windows 当前用户加密。更新仅接受预置公钥签名的版本，拒绝降级、篡改和越界解压。

专网使用 Tailscale / WireGuard 端到端加密。这不等于绝不会被劫持：账号、授权设备或电脑本身失陷仍会影响安全。本程序未经独立安全审计，客户端与安装器暂没有商业代码签名；官方组件已核对有效签名与哈希。

你和老婆各自控制不同电脑，使用独立连接。一起控制同一台时，会共享屏幕、鼠标和键盘；本版不创建两个相互隔离的 Windows 桌面。

你们可使用不同 VPN，但尚未确定具体客户端。部分 VPN 会拦截专网流量或产生地址冲突，详见 官方兼容说明。软件不自动关闭 VPN 或修改它的规则，兼容性需要分别实测。

QQ 截图与网页上传

安装版启用引擎的图片剪贴板和文件复制。连接后，本机 QQ 截图可在远端支持图片粘贴的网页尝试 Ctrl+V；具体 QQ、浏览器和网页版本需要实测。

“画质与帮助 → QQ 截图助手”可在你点击后读取图片、保存 PNG，并在本机拖入网页。它不会持续读取剪贴板。

本机 QQ 截图直接拖进远端网页上传区域，尚未完成。图片剪贴板、文件传输和本机拖放不等于跨电脑网页拖放；这项需要补充实现与实际网页验证。

停止接入与卸载

退出管理器不等于停止远控服务。若不希望被连接，请在远控引擎中停止接入。Windows 应用列表中的“巫妖的远程魔导控制系统”可卸载管理器；卸载时会尝试恢复接入前的选项，停止并禁用由本程序新安装的远控服务，并保留个人数据备份。

Tailscale 和 RustDesk 是独立组件，可在 Windows 应用列表分别卸载。系统组件的安装、修复和卸载需要本人允许 Windows 管理员提示。

检查记录与源码

包内包含源码、构建脚本、对应上游引擎源码档案、许可与“测试记录.json”。记录区分本机检查、系统组件安装、异地画面与拖放。配对口令、设备名单和发布私钥不随公开包分发。

个人数据：%LOCALAPPDATA%\OwnDesk。程序：%LOCALAPPDATA%\Programs\OwnDesk。远控引擎 RustDesk 1.5.0；专网安装源 Tailscale 1.102.2 官方 MSI。
